# GrAF Explorer

A PyQt5 desktop application for viewing and editing `.graf` data files: an
interactive plotting/inspection GUI built on top of the
[`graf-format`](https://github.com/Grant-Giesbrecht/graf) and
[`stardust-tools`](https://github.com/Grant-Giesbrecht/stardust) libraries.

## Install

```bash
pip install graf-explorer
```

## Run

```bash
graf-explorer            # launch the app
graf-explorer file.graf  # open a file directly
```

You can also run it as a module:

```bash
python -m graf_explorer
```
